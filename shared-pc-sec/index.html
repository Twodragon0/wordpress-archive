공용 PC 사용 후 개인정보 보호 및 보안 가이드 🖥🔒✨

2024-12-24

공용 PC 사용 후 개인정보를 안전하게 보호하기 위해 필수로 해야 할 작업들을 안내합니다.

꼭 실천하여 소중한 데이터를 지키세요! 💾⚠️

1️⃣ 공인인증서 삭제 🗝️

파일 검색 및 삭제 방법 🔍

  • 아래 키워드를 검색창에 입력하여 인증서를 찾습니다:
  • Windows: NPKI, .pfx, .p12, .der, .key, cn=
  • macOS: Finder에서 동일한 키워드 검색.
  • 검색된 파일을 휴지통으로 이동 🗑️ > 완전 삭제 ❌.

브라우저 인증서 삭제 방법 🌐

  • Chrome: 설정 ⚙️ > 개인정보 및 보안 > 인증서 관리 > 인증서 선택 > 삭제 🗑️
  • Internet Explorer (IE11): 도구 🔧 > 인터넷 옵션 > 콘텐츠 > 인증서 > 대상 인증서 선택 > 삭제 🗑️
  • Safari: Safari > 기본 설정 ⚙️ > 인증서 > 대상 인증서 선택 > 삭제 🗑️

2️⃣ 인터넷 사용 기록 삭제 🕵️‍♀️ (Windows와 macOS 브라우저 공통)

• Chrome: 방문 기록 (History) > 인터넷 사용정보 삭제 (Clear browsing data)

✅ 방문 기록 📜

✅ 쿠키 및 기타 사이트 데이터 🍪

✅ 캐시된 이미지 및 파일 🗂️

• Safari: Safari > 기본 설정 ⚙️ > 개인정보 보호 > 모든 웹사이트 데이터 제거 🗑️

• Internet Explorer (IE11): 도구 🔧 > 인터넷 옵션 > 일반 탭 > 검색 기록 삭제 🗑️

✅ 임시 인터넷 파일 📂

✅ 쿠키 🍪

✅ 기록 📜

• FireFox: 설정 ⚙️ > 개인정보 및 보안 > 쿠키와 사이트 데이터 > 데이터 삭제 🗑️

3️⃣ 다운로드 기록 및 파일 삭제 📂

  1. 다운로드 폴더에서 사용한 모든 파일 삭제.
  2. 휴지통을 반드시 비우세요 🗑️❌.
  3. 브라우저 다운로드 기록 삭제 🌐
    • Chrome: 방문 기록 (History) > 다운로드 기록 삭제 🗂️❌
    • Safari: Safari > 히스토리 > 다운로드 기록 삭제 🗂️
    • Internet Explorer (IE11): 도구 🔧 > 다운로드 보기 > 기록 삭제 📜❌

4️⃣ 저장된 비밀번호 및 로그인 정보 삭제 🔑

  • Chrome: 설정 ⚙️ > 비밀번호 > 저장된 비밀번호 관리 > 삭제 🗑️
  • Safari: Safari > 기본 설정 ⚙️ > 비밀번호 > 저장된 로그인 정보 삭제 ❌
  • Internet Explorer (IE11): 도구 🔧 > 인터넷 옵션 > 콘텐츠 > 자동 완성 설정 > 기록 삭제 🗑️

5️⃣ 공용 PC에서 반드시 설정해야 할 보안 조치 🔒

  1. 🛡️ 브라우저 시크릿 모드 사용
    • 로그인 시 시크릿 모드 또는 개인 창을 사용하세요.
    • Chrome: 새 시크릿 창 🕶️
    • Safari, FireFox: 새 개인 창 🔏
  2. 🔓 자동 로그인 비활성화
    • 로그인 시 비밀번호 저장 또는 자동 로그인 기능을 거부하세요.
  3. ⛔ 화면 잠금 활성화
    • 자리를 비울 때는 반드시 화면을 잠그세요.
    • Windows: Windows 키 + L 🔐
    • macOS: Control + Command + Q 🔐
  4. 🔐 2단계 인증 활성화
    • 계정 보안을 위해 2단계 인증을 설정해 추가 방어선을 구축하세요.
  5. 🚪 로그아웃 및 장치 회수
    • 사용한 계정에서 반드시 로그아웃하고, USB나 외장 메모리는 PC에 남기지 말고 회수하세요.
